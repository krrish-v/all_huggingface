# all_huggingface

A collection of AI and machine learning experiments exploring Hugging Face models, LLMs, Utility methods, model evaluation, serving, and document understanding.

## Repository Structure

```
all_huggingface/
│
├── Graph_Rag/
│   └── Graph-based retrieval experiments
│
├── icon/
│   └── Icon and visual assets
│
├── input/
│   └── Input files and experimental resources
│
├── model_evaluation/
│   ├── MadriMed-VL-2B_evaluation.ipynb
│   └── Other evaluation resources and experiments
│
├── model_serving/
│   └── Model inference and serving experiments
│
├── table_detection/
│   └── Table detection experiments
│
└── README.md
```

---

## Purpose

This repository serves as a workspace for experimenting with open-source AI models, exploring machine learning techniques, and building practical AI applications.
